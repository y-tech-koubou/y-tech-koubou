# スプラッシュ画面 構成案

Yテック工房ブランド配下4アプリ共通のスプラッシュ画面デザイン仕様。

---

## デザイン原則

1. **静かな立ち上がり**: 派手なアニメーションや効果音は使わない
2. **ブランド一貫性**: 4アプリで配色・余白・要素位置を統一
3. **プロダクト個別性**: ロゴマークの色味のみアプリごとに微調整
4. **2秒以内退場**: スプラッシュは演出ではなく品質保証の証

---

### 寸法仕様

| 要素 | 仕様 |
|---|---|
| 背景色 | 生成り `#FAF7F2` |
| ロゴマーク | 120 × 120px、垂直中心から上30%に配置 |
| ブランド名（和文） | Noto Serif JP Medium 24px、色 `#2D5A2D`、letter-spacing 0.08em |
| ブランド英名 | Cormorant Garamond Medium 12px、色 `#6B8E5A`、letter-spacing 0.4em、大文字 |
| プロダクト名 | Noto Sans JP Regular 14px、色 `#6B7280`、下から15%地点 |
| 余白上下 | 共に最低60px確保 |

## アプリ別のアクセント

各アプリでロゴマークの3枚の葉の色を1色だけ変更し、識別性を高める。

| アプリ | 葉のアクセント色 | 由来 |
|---|---|---|
| architect-quiz | 朱 `#A0382A` | 建築の朱印・落款 |
| koji-app | 麹色 `#C99A4A` | 麹の発酵色（[[project_hugtime_hp_design]] と整合） |
| invest-ai | 若葉 `#6B8E5A` | ブランド標準色（IT＝中立） |
| africa-map | 砥粉 `#EDE7DC` | 大地の色（ベージュ系） |

葉の色変更は1枚のみで、他2枚は標準の苔緑 `#2D5A2D` を維持する。
これにより「同じブランド・異なるプロダクト」が一瞥で伝わる。

## 表示時間とトランジション

| フェーズ | 時間 | 動作 |
|---|---|---|
| フェードイン | 200ms | 透明度 0 → 1（ロゴ・テキスト同時） |
| 表示 | 800ms | 静止 |
| フェードアウト | 200ms | 透明度 1 → 0 |
| 合計 | 1,200ms | 1.2秒で退場 |

**禁止**:
- ロゴの回転・スケール・スライド
- パーティクル・グロー・パルスエフェクト
- 効果音

## Expo 実装上のメモ

```json
// app.json に記述するスプラッシュ設定（参考）
{
  "expo": {
    "splash": {
      "image": "./assets/splash.png",
      "resizeMode": "contain",
      "backgroundColor": "#FAF7F2"
    }
  }
}
```

スプラッシュ画像は 1242×2436px（iPhone XS 縦）を基準に作成し、
Expo がデバイス別にリサイズする。ロゴ位置は画像内で固定。

ダークモード切替は `splash.dark` を別途定義する。
